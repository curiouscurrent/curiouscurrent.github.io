Gradient Descent From Scratch

A curated collection of Kaggle notebooks covering Gradient Descent from first principles to practical implementations in Machine Learning.

Notebooks

  • Learn Gradient Descent Learn the intuition behind gradient descent, loss functions, gradients, and iterative optimization from scratch.
  • Simple Linear Regression Implement gradient descent from scratch to optimize the parameters of a simple linear regression model.
  • Changing Intercept Optimize both slope and intercept simultaneously and visualize their convergence during training.
  • Stochastic GD Understand how Stochastic Gradient Descent updates parameters using one training example at a time.
  • Batch GD Extend gradient descent to multiple input features using vectorized batch optimization.
  • Mini-Batch GD Explore mini-batch gradient descent, balancing convergence speed and computational efficiency.
  • Perceptron Loss Implement gradient descent for perceptron loss and understand linear classification optimization.
