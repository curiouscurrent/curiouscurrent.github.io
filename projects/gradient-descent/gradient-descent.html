Gradient Descent

A collection of interactive Kaggle notebooks covering the fundamentals of Gradient Descent, its variants, and practical implementations from scratch.

Learn Gradient Descent

An introductory notebook explaining the intuition behind gradient descent, how optimization works, and why iterative parameter updates help minimize loss functions.

Gradient Descent for Simple Linear Regression

Implements gradient descent from scratch to train a simple linear regression model, illustrating how slope and intercept converge toward the optimal solution.

Gradient Descent with Changing Intercept

Demonstrates simultaneous optimization of both slope and intercept, showing how parameter updates affect convergence and prediction accuracy.

Stochastic Gradient Descent (SGD)

Explores stochastic gradient descent, where model parameters are updated after every training sample for faster learning and improved scalability.

Batch Gradient Descent on N-Dimensional Data

Extends gradient descent to multivariate datasets, demonstrating batch optimization across multiple input features using vectorized computations.

Mini-Batch Gradient Descent

Introduces mini-batch gradient descent, balancing computational efficiency and convergence stability by updating parameters using small batches of data.

Perceptron Loss using Gradient Descent

Illustrates how gradient descent can optimize the perceptron loss function, providing insight into linear classification and decision boundary learning.
